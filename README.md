# trajkit tutorial

`trajkit` is a small toolkit for loading, analyzing, and visualizing robot trajectory datasets.

## 1) Install

```bash
python -m pip install -e .
```

## 2) Run the demo test

```bash
python test.py
```

This prints:
- dataset summary
- feature table size
- top outlier
- one trajectory/frame example
- image channel keys
- and pops up one decoded image with `plt.show()`

## 3) Load your own dataset

```python
from trajkit import TrajectoryDataset

ds = TrajectoryDataset.load("data/your_dataset", include_images="paths")
print(ds.summary())

# Optional: export to a canonical file for reuse/share.
ds.save("data/your_dataset_canonical.parquet")

# Optional: make CSV-friendly columns by expanding vector lists.
ds.save(
    "data/your_dataset_flat.csv",
    expand_vectors=True,
    drop_vector_columns=True,
)
```

Expected tabular schema (CSV/Parquet/JSON/JSONL):

- required per frame:
  - `trajectory_id` (string)
  - `t` (float timestamp; if missing, row index is used)
  - `x`, `y` (float position)
- optional:
  - `z` (float, defaults to `0.0` if missing)
  - `frame_index` (int, used to build `frame_id`; otherwise generated by sorting within each trajectory by `t`)
  - `state_vec` (list[float], see channel spec below)
  - `action_vec` (list[float])
  - `wrench_vec` (list[float], first 6 channels are `[fx, fy, fz, tx, ty, tz]`)
  - image columns such as `image_rgb_path`, `image_depth_path`, `image_0_path`, or `image_*_bytes`

`state_vec` spec:

- recommended canonical order (most compatible): `[x, y, z, eef_qx, eef_qy, eef_qz, eef_qw]`
- minimum for recovering position from state only: first 2 values must be `[x, y]` (3rd is treated as `z` if present)
- if both explicit `x/y/z` and `state_vec` exist, `x/y/z` are used as the trajectory coordinates
- if `x/y` are missing but `state_vec` exists, loader uses:
  - `x = state_vec[0]`
  - `y = state_vec[1]`
  - `z = state_vec[2]` (or `0.0` if missing)
- Bridge-style datasets may produce a 6D state vector `[x, y, z, roll, pitch, yaw]`; this is also accepted

Accepted aliases (auto-renamed):
- `trajectory_id`: `episode_index`, `episode_idx`
- `t`: `timestamp`, `time`, `ts`, `elapsed_s`
- `x`: `tx`, `pos_x`, `position_x`, `eef_x`
- `y`: `ty`, `pos_y`, `position_y`, `eef_y`
- `z`: `tz`, `pos_z`, `position_z`, `eef_z`

Minimal CSV example:

```csv
trajectory_id,t,x,y,z
traj_0001,0.00,0.12,-0.03,0.51
traj_0001,0.04,0.13,-0.01,0.50
traj_0002,0.00,-0.20,0.15,0.48
```

`include_images`:
- `"none"`: fastest
- `"paths"`: load image paths
- `"bytes"`: load image bytes

Canonical export notes:
- `TrajectoryDataset.save(...)` writes normalized columns in one place (`trajectory_id, frame_id, t, x, y, z, ...`).
- `expand_vectors=True` turns `state_vec/action_vec/wrench_vec` into scalar columns (`state_vec_0`, etc.), often easier for spreadsheets/SQL/ML tools.
- Supported export formats: `.parquet`, `.csv`, `.jsonl`.

## 4) Basic analysis

```python
print(ds.feature_table().head())
print(ds.cluster(k=4).medoid_ids)
print(ds.find_outliers(top_k=5))
# if force/torque exists, feature_table also includes:
# mean_force_norm, max_force_norm, mean_torque_norm, max_torque_norm
```

## 5) Frame-level access

```python
traj = ds[0]
print(traj.get_frame(idx=0))
print(traj.frame_view(start=0, stop=64, step=2).x.shape)
print(traj.image_channels(kind="path").keys())  # rgb/depth/other
img = traj.get_image(idx=0, modality="rgb", decode=True)
# img is a numpy array, ready for plt.imshow(img)
print(traj.force_torque_vectors())  # None if dataset has no F/T
```

`source` supports:
- `"auto"` (default): try bytes first, then path
- `"bytes"`: only bytes columns
- `"path"`: only path columns

ax = ds.plot_coverage()  # matplotlib axis

## 7) Interactive web app

Run a minimal, English-first web UI with drag-and-drop upload:

```bash
python -m pip install -e ".[ui]"
streamlit run web_app.py
```

What you get:
- drag-and-drop dataset files (or one `.zip` dataset folder)
- quick metrics (`num_trajectories`, `num_points`, feature rows, missing timestamps)
- sample trajectory plot (`x-y`)
- feature histogram (`mean_speed`, `path_length`, etc.)
- outlier table and feature preview

Large-file tips:
- set **Processing mode** to `Fast (Large files)` for responsive UI on big datasets
- keep **Image loading mode** as `none` unless you really need image payloads
- disable **advanced analytics** if you only need quick data inspection
- upload cap is configured in `.streamlit/config.toml` (`maxUploadSize = 2048`, in MB)

## Supported formats

- `.parquet` / `.csv` / `.json` / `.jsonl`
- `.npy` / `.npz`
- `.hdf5` / `.h5`
- `.rlds`
- `LeRobotDataset`
